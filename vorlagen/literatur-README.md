# Literatur

Lokal gespeicherte Leitlinien, Empfehlungen und Fachinformationen, auf die
sich die Beurteilung und die Kapitel der Akte stützen. Zu jeder Quelle
liegen das Original-PDF und eine Textfassung zum Durchsuchen, geschrieben
von `literatur-text` in der Reihenfolge des Lesens. Seiten, deren Inhalt
nicht als Text darin steht, nennt die Spalte „Quelle“; sie liest man im
PDF.

Die gespeicherte Fassung ersetzt das Nachschlagen des Inhalts, nicht die
Prüfung auf eine neuere Version; wann neu geprüft wird, steht im Subagenten
`leitlinien-recherche` des Plugins.
