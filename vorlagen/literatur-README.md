# Literatur

Lokal gespeicherte Leitlinien, Empfehlungen und Fachinformationen, auf die sich
`BEURTEILUNG.md` stützt. Zu jeder Quelle liegen das Original-PDF und eine Textfassung
(`pdftotext -layout`) zum Durchsuchen.

Die gespeicherte Fassung ersetzt das Nachschlagen des Inhalts, nicht die
Prüfung auf eine neuere Version; wann neu geprüft wird, steht im Subagenten
`leitlinien-recherche` des Plugins.
