# Die Rangfolge der Quellen kennt nur die Medizin

Das README verspricht Beratung in Medizin, Physiotherapie, Ernährung und
Sport. Die Rangfolge in `skills/leitlinie/SKILL.md:8-12` nennt aber nur
AWMF-Leitlinien, Nationale VersorgungsLeitlinien und Cochrane. Für eine Frage
zu Training oder Ernährung sagt sie nicht, welche Quelle Vorrang hat, etwa
DGE, WHO-Bewegungsempfehlungen, KNGF- oder JOSPT-Leitlinien gegenüber einer
einzelnen Studie. STIKO steht im README, aber in keinem Skill.

Wo diese Quellen zu finden sind, weiß ein Modell selbst; eine Liste von
Fundorten braucht es nicht.
