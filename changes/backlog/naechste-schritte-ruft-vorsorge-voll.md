# naechste-schritte führt den ganzen Skill vorsorge aus

`naechste-schritte` ermittelt die fällige Vorsorge mit dem Skill `vorsorge`
(`skills/naechste-schritte/SKILL.md:16-17`). Der prüft „jede Quelle in
Schritt 3 jedes Mal“ (`skills/vorsorge/SKILL.md:9-11`): G-BA-Richtlinien,
die Leitlinie jeder Diagnose, die Fachinformation jedes Mittels,
STIKO-Empfehlungen. Was in `BEURTEILUNG.md` mit nicht veralteter Prüfung
steht, wird übersprungen (`:15-18`), sonst wird alles neu gesucht. Eine
kurze Frage „was steht an?“ kann so sehr lange dauern und viele Abrufe
kosten, obwohl nur die Fälligkeiten gebraucht werden.
