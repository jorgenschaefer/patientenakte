# Leitlinien lassen sich nicht ausdrücklich auf einmal prüfen

`skills/leitlinie/SKILL.md:28-33` prüft eine Leitlinie erst, wenn sie für eine
Empfehlung gebraucht wird: ob „gültig bis“ vorbei ist oder die letzte Prüfung
älter als drei Monate ist. Einen Schritt, mit dem der Benutzer alle Quellen in
`literatur/README.md` (Spalten „Gültig bis“ und „Geprüft“,
`vorlagen/literatur-README.md:11`) auf einmal durchsehen lassen kann, gibt es
nicht.

Das soll ein ausdrücklicher Schritt sein, den der Benutzer anstößt. Beim Start
einer Sitzung oder ungefragt im Gespräch soll es nicht passieren.
