# BEURTEILUNG.md über einen gemeinsamen Skill schreiben

`BEURTEILUNG.md` soll über einen gemeinsamen Skill geschrieben und geändert
werden, damit das Vorgehen überall gleich ist, so wie `AKTE.md` nur über
`akte-aktualisieren` geändert wird.

Heute schreibt jede Stelle auf ihre eigene Weise hinein:

- `skills/neue-information/SKILL.md:53` (Gegenanzeigen unter „Offen“ oder
  „Warnzeichen“) und `:60-67` (betroffene Einträge anpassen, committen);
- `skills/vorsorge/SKILL.md:67-69`;
- `skills/leitlinie/SKILL.md:46-54` (Eintrag und Abschnitt „Quellen“);
- `skills/naechste-schritte/SKILL.md:34-37`;
- die freie Beratung nach `regeln.md:105-109`;
- angelegt wird sie aus der Vorlage in `skills/anamnese/SKILL.md:15`.

Gegenprüfung und Commit regelt nur `regeln.md` (`:105-109`, `:120-121`,
Abschnitt „Gegenprüfung“). `vorsorge` und `neue-information` sagen schlicht
„Committen.“, `leitlinie` und `naechste-schritte` haben keinen
Commit-Schritt.
